# What to set in GitHub (only)

Canonical model: [account-selection-and-ci-credentials](superpowers/specs/2026-07-24-account-selection-and-ci-credentials.md)

## Repository secrets (shared)

| Name | Purpose |
|------|---------|
| `R2_ACCOUNT_ID` | OpenTofu state (Cloudflare R2) |
| `R2_ACCESS_KEY_ID` | OpenTofu state |
| `R2_SECRET_ACCESS_KEY` | OpenTofu state |

## Environment secrets (per Neon **account**, only if apps use that org)

| Environment name | Secret name | When |
|------------------|-------------|------|
| `neon--identity` | `API_KEY` | Any app with `neon.account: identity` |
| `neon--payments` | `API_KEY` | Any app with `neon.account: payments` |
| `neon--…` | `API_KEY` | Same pattern for each key in `config/neon-accounts.yaml` |

Create with:

```bash
./scripts/bootstrap-neon-account.sh --account identity --sync-github-env
# or UI: Environments → neon--identity → secret API_KEY
```

**Neon API key is only used when the app selects that Neon account.**  
Apps without `neon.account` never load a Neon key.

## Not GitHub secrets

| Thing | Where |
|-------|--------|
| GCP project / WIF / deploy SA | `config/gcp-accounts.yaml` (public registry) + WIF OIDC |
| DATABASE_URL | Secret Manager, written by OpenTofu |
| App crypto (csrf, Hydra secrets, …) | Secret Manager, generated by OpenTofu on apply |
| Optional Google OAuth | OpenTofu vars → Secret Manager (optional) |

## Deprecated (do not use)

| Old | Why |
|-----|-----|
| Repo secret `NEON_API_KEY` | One key cannot serve multiple Neon orgs |
| Env `neon-identity` + `NEON_API_KEY` | Renamed to `neon--identity` + `API_KEY` |
| Env `gcp-identity-prod` with secrets | GCP has no deploy secrets; optional protection env is `deploy--identity--stawi-prod` (empty) |

## Optional protection environments (no secrets)

| Name | Purpose |
|------|---------|
| `deploy--{gcp_account}--{env}` e.g. `deploy--identity--stawi-prod` | Required reviewers only. Used only if the app has **no** Neon account. If the app uses Neon, the job uses `neon--…` instead (one environment per job). |
