# What to set in GitHub (only)

Canonical credential model for this repo.

## Repository secrets (shared — that's all)

| Name | Purpose |
|------|---------|
| `R2_ACCOUNT_ID` | OpenTofu state (Cloudflare R2 bucket `cloud-tofu-state`) |
| `R2_ACCESS_KEY_ID` | OpenTofu state |
| `R2_SECRET_ACCESS_KEY` | OpenTofu state |
| `SOPS_AGE_KEY` | Private age key matching `.sops.yaml` — decrypts `credentials/{gcp,neon}/**` |
| `CLOUDFLARE_API_TOKEN` | **DNS:** Zone:DNS:Edit on `stawi.org` for `edge-lb-*` OpenTofu. **API gateway Worker:** also Account Workers Scripts:Edit + Zone Workers Routes:Edit (same token or a broader one). |
| `CLOUDFLARE_ACCOUNT_ID` | Optional — only if `wrangler deploy` for `edge/cloudflare-api-gateway` cannot auto-detect the account |

Core deploy (services only) works without `CLOUDFLARE_API_TOKEN`.  
Public product API (`api.stawi.org`) uses the **Cloudflare Worker** in `edge/cloudflare-api-gateway` (workflow `edge-api-gateway.yml`).  
Host LBs (`edge-lb-*`) still need DNS:Edit when applied.

## How credentials are selected (no GitHub Environments)

```
app.yaml
  gcp.account + env  → credentials/gcp/<account>/<env>/auth.yaml   (WIF + project)
  neon.account       → credentials/neon/<account>/auth.yaml        (API key, optional)
```

CI steps:

1. `resolve-app-context.sh` — which accounts/paths for this app
2. `load-sops-credentials.sh` with `SOPS_AGE_KEY` — decrypt and export `TF_VAR_*` + WIF
3. `google-github-actions/auth` — WIF to the deploy SA
4. `tofu plan|apply` — state in R2 key `cloud-deployment/apps/<app>/<env>/terraform.tfstate`

Neon API key is loaded **only** when `app.yaml` has `neon.account`.

## Not GitHub secrets

| Thing | Where |
|-------|--------|
| GCP project / WIF / deploy SA | SOPS `credentials/gcp/...` (+ public mirror in `config/gcp-accounts.yaml`) |
| Neon org API key | SOPS `credentials/neon/<account>/auth.yaml` |
| DATABASE_URL | Secret Manager, written by OpenTofu |
| App crypto (csrf, Hydra secrets, …) | Secret Manager, generated by OpenTofu on apply |
| Optional Google OAuth | OpenTofu vars → Secret Manager (optional) |

## Operator setup once

```bash
# 1) Put the private age key in GitHub (Settings → Secrets → Actions)
#    Name: SOPS_AGE_KEY
#    Value: AGE-SECRET-KEY-1...  (same private key that decrypts deployment.infra)

# 2) R2 (already provisioned bucket cloud-tofu-state)
#    R2_ACCOUNT_ID, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY

# 3) Bootstrap accounts into SOPS (if not already)
./scripts/bootstrap-gcp-account.sh --account identity --env stawi-prod --project stawi-identity
./scripts/bootstrap-neon-account.sh --account identity --api-key "$API_KEY" \
  --org-hint "Stawi Identity" --org-id org-rapid-mountain-41505493

# Platform domain (required for platform-* apps)
./scripts/bootstrap-gcp-account.sh --account platform --env stawi-prod --project stawi-platform
./scripts/bootstrap-neon-account.sh --account platform --api-key "$PLATFORM_NEON_API_KEY" \
  --org-hint "Stawi Platform" --org-id org-calm-cell-68997035

# 4) Cloudflare DNS for public edge (edge-lb-identity / edge-lb-platform)
#    Token needs Zone → DNS → Edit on stawi.org (same scope as deployment.infra 04-dns).
#    gh secret set CLOUDFLARE_API_TOKEN --body "$TOKEN"
```
